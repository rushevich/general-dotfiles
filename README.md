# GNU Emacs Configuration

This repository mainly serves the purpose of tracking my from-scratch GNU Emacs configuration. I started using Emacs in *July, 2026,* and it serves as my software-of-choice for mostly everything that I can squeeze out of it. The configuration is also home to my very own `blue-dark-theme.el` Emacs theme, which anyone is of course free to use by copying the code.
